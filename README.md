# tomiwaadesanya.tech

Portfolio of Tomiwa G. Adesanya, desktop application developer.

Static site served by GitHub Pages. No build step: edit and push.

- `index.html`: page structure
- `css/style.css`: styles
- `js/data.js`: projects, contact details and form settings
- `js/main.js`: rendering, live release downloads, media viewer, hire form
- `assets/`: icons, screenshots and films
